# Лабораторная работа №1. Реализация БД в 3NF

**Вариант 14:** Система учета в видеопрокате
**СУБД:** MySQL

## Описание
База данных видеопроката: каталог фильмов, физические диски, клиенты, сотрудники, выдачи и платежи. Структура приведена к третьей нормальной форме (3NF), справочники вынесены в отдельные таблицы, связь «выдача - диски» реализована через таблицу `rental_item`.

## Файлы
- `lab1_videorental_3nf.sql` - SQL-код создания БД, тестовые данные и проверочный запрос
- `schema.jpg` - даталогическая модель (схема БД)
- `result.jpg` - результат проверочного запроса

## Таблицы (12)
genre, media_type, copy_status, job_position, payment_method, movie, copy, customer, employee, rental, rental_item, payment
